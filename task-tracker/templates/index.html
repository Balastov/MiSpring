Синхронизация с календарём

Подпишитесь на ваши уроки — они будут обновляться автоматически.

Mac (приложение Календарь):

  1. Скопируйте ссылку кнопкой выше
  2. В приложении Календарь: Файл → Новая подписка на календарь
  3. Вставьте ссылку → Подписаться

iPhone / iPad:

  1. Скопируйте ссылку кнопкой выше
  2. Настройки → Календарь → Учётные записи → Добавить учётную запись → Другое
  3. Добавить подписной календарь → вставьте ссылку → Сохранить
